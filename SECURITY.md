# Security

Report vulnerabilities privately via [GitHub Security
Advisories](https://github.com/alinotfoundbtw/sounding/security/advisories/new) on
this repository.

Please do not open a public issue for a vulnerability report.

## Scope note

`sounding` performs static analysis only. It does not execute, connect to, or
scan anything. If you find a case where it does, that is a vulnerability in
this tool and I want to know.
